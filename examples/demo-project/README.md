# Demo project

This is sample content for Paso. It is not user work.

The first scene has three complete snapshots. They show an input box, add an
arrow, then add an output box. Existing elements keep their IDs. All three
steps use the same SVG image in the project assets folder.

The second scene has one recap step. Read the order arrays in each parent
JSON file to find the presentation order. Folder names do not set the order.
